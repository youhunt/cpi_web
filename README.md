# Chugoku Paints Indonesia - CodeIgniter 4 Preview

Cara pasang:
1. Buat project CI4:
   composer create-project codeigniter4/appstarter chugoku-ci4
2. Copy folder `app` dan `public` dari paket ini ke project CI4.
3. Set `.env`:
   app.baseURL = 'http://localhost:8080/'
4. Jalankan:
   php spark serve
5. Buka:
   http://localhost:8080

Catatan:
- Ini versi frontend preview CI4.
- Belum termasuk CMS/admin.
- Sudah dipisah layout, partial header, footer, floating social, CSS, JS, dan images.
